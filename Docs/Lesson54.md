# Практическая 5.4 — структура и оформление проекта

За основу взят проект взаимодействия между Blueprint из практической 3.8 в том же StealthShooter. Новая игровая механика не добавлялась. Общие ресурсы 4.4 также обновлены, чтобы сохранить работоспособность связанного виджета.

## Изменения

| Область | Результат |
| --- | --- |
| Структура контента | Core, Interaction/Lighting, Interaction/GroupControl, MaterialLibrary, Examples и Maps |
| Общий интерфейс | BPI_Switchable находится в Core |
| Материалы | Вынесены в библиотеку и получили имена по назначению |
| Переменные | IsOn → bOn, Bound → bBound, IsNearby → bNearby |
| Категории | Настройки, состояние, контекст UMG, события и диагностика разделены |
| Обработчики | OnSwitchChanged, OnEnableClicked, OnDisableClicked |
| Функции | Явные Return; максимум 30 узлов в реализованных функциях проверяемого модуля |
| Граф группового пульта | EventGraph сокращён с 51 до 12 узлов; выделены SetGroupState и InitializeControls |
| Комментарии | Пояснения к функциям и отдельным потокам событий |
| Ссылки | 25 переносов через Unreal, пересохранение зависимостей и удаление redirector-объектов |
| Документация и инструменты | Пути обновлены; для прежних имён добавлен общий resolver |

Все 28 собственных ресурсов сохранены. Карты остались на своих путях: L_SwitchableRoom, L_GroupControl и L_BlueprintLab. Число сохранённых акторов: 22, 36 и 27 соответственно. Исходные персонаж, камера, ввод и контент Epic не изменены. Отдельный проект предыдущей игры «Увернись от камня» не затронут.

[Конвенции проекта](ProjectStyle.md) описывают принятую структуру и область применения. [Таблица путей](AssetPathChanges54.json) позволяет найти каждый перенесённый ресурс.

## Просмотр

Откройте StealthShooter.uproject в Unreal Engine 5.8.3. Стартовая карта — L_SwitchableRoom. Нажмите Play, подойдите к консоли и нажмите E в радиусе 2,5 м. Повторное нажатие включает свет. Для связанной практической 4.4 откройте L_GroupControl: у трёх пультов появляются отдельные панели UMG.

## Проверки

- [Структура и Blueprint](StyleValidation54.json): 253 проверки, все 28 ресурсов, их имена и расположение, отсутствие redirector-объектов, компиляция собственных Blueprint без ошибок и предупреждений, категории и именование полей, комментарии, Return и размер функций модуля взаимодействия.
- [Play — кнопка и диспетчер](Style54SwitchableRuntime.json): 267 проверок, включая 12 повторных переключений, точную границу радиуса, подписки, повторную подписку, отсутствующую ссылку и уничтожение подписчика. Дополнительно физической клавишей E проверены нажатие вне радиуса, выключение и повторное включение всех четырёх светильников.
- [Play — группы и UMG](Style54GroupRuntime.json): 55 проверок появления/скрытия панелей, независимости трёх групп, состояния кнопок, повторных циклов и изменения массивов.
- После переноса проект закрыт, выполнено исправление redirector-ссылок и проект заново открыт перед проверками.
- Все Python-инструменты прошли проверку синтаксиса. .gitignore и Git LFS сохранены.

Скринкаст 5.4 записан заново после изменений: обзор структуры, обработчик OnSwitchChanged с комментарием и Return, подход к кнопке и реальное переключение света клавишей E. Ролик — 45 секунд, MP4/H.264, 1280×720, русские подписи. Файл передаётся отдельно; в него не включены браузер, личные уведомления или содержимое учебного портала.
