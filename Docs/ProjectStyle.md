# Конвенции StealthShooter

Правила для проекта взаимодействия из модуля 3 и общих ресурсов модуля 4. Основа — материалы 5.2/5.3 Skillbox и [Allar Style Guide v2](https://github.com/Allar/ue5-style-guide/tree/v2). Это согласованный набор правил проекта, а не утверждение о соответствии всем разделам руководства для любых типов игр.

## Контент

Все собственные ассеты находятся в `Content/StealthShooter`. Папки именуются в PascalCase, идентификаторы содержат только ASCII-буквы, цифры и подчёркивания. Текст интерфейса и комментарии могут быть на русском или английском.

```text
StealthShooter/
  Core/                         общий BPI_Switchable
  Examples/Foundations/          сохранённые учебные примеры модулей 1–2
  Interaction/
    Lighting/                   кнопка и светильник из 3.8
    GroupControl/               групповой пульт и его UMG-виджет
  Maps/                         три сохранённые учебные карты
  MaterialLibrary/
    Environment/                общие материалы комнат
    Lighting/                   материалы светильника и пульта
    Examples/                   материалы прежних примеров
```

Материалы используют конкретные имена: M_LampBulb_On / Off, M_LightFixture, M_SwitchCap, M_LabRoom_Floor / Wall / Accent / Text. Префиксы ресурсов: BP_, BPI_, WBP_, M_, S_, L_. Общий интерфейс вынесен в Core; ресурсы одной функции расположены рядом, а не разделены по типам в общие папки Blueprints или UI.

Контент Epic и предоставленная учебная заготовка вне StealthShooter сохраняют исходные пути и атрибуцию. Это отдельные импортированные наборы, а не глобальные ассеты нового модуля. Старые примеры в Examples сохранены как учебная основа; рефакторинг внутренней логики модулей 1–2 в задание 5.4 не входит.

## Blueprint

- Члены класса: PascalCase, булевы поля — bOn, bBound, bNearby. Имена коллекций — во множественном числе без суффикса Array.
- Настройки экземпляра: категория Interaction|Configuration. Состояние: Interaction|State. Контекст виджета: UI|Context. Счётчики: Diagnostics. Диспетчер: Interaction|Events.
- Функции обозначают действие; запрос состояния — IsSwitchOn. Диспетчер и обработчики начинаются с On: OnSwitched, OnSwitchChanged, OnEnableClicked, OnDisableClicked.
- Одна функция выполняет одну связанную задачу и содержит не более 30 узлов. У реализованных функций есть явные Return, включая ранние выходы. Тело ForEach продолжает обход, Return располагается после Completed, чтобы не оборвать цикл после первого элемента.
- Декларации интерфейса без выходов, диспетчер, события и стандартный Construction Script не рассматриваются как обычные реализованные функции с Return.
- Логические блоки имеют поясняющие комментарии. Узлы разложены по потоку исполнения; ссылки проверяются перед обращением.
- Изменяемые Blueprint компилируются без ошибок и предупреждений перед сохранением.

## Переносы и совместимость

Ресурсы перемещаются средствами Unreal; затем обновляются ссылки и удаляются redirector-объекты. [Таблица путей](AssetPathChanges54.json) фиксирует переносы. Инструменты прежних уроков используют project_paths.py для разрешения исторических имён. В готовой игровой логике ссылки ведут на новые ресурсы; Python и инструменты редактора для запуска не требуются.

Служебные папки Saved, Intermediate, DerivedDataCache, Binaries и Deliverables исключены через .gitignore. Бинарные ресурсы хранятся в Git LFS.
